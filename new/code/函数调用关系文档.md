## 2. 模块间调用概览

### 2.1 调用方向总表

| 源模块 | → 目标模块 | 用途 |
|--------|-----------|------|
| `runtime/` | → `port/` | 硬件操作(IMU/Encoder/Motor/Camera/Timer/Power)、诊断输出、性能计数 |
| `runtime/` | → `platform/` | 通信链路(Assistant/SteeringMedia) |
| `runtime/` | → `legacy/` | 感知流水线(Otsu/BEV/Element/Ref)、控制算法(PID/Yaw/WheelMixer) |
| `runtime/` | → `runtime/` | 模块内部调用（调参状态、运动监督、控制决策等） |
| `platform/` | → `port/` | 诊断输出、时间戳、子系统启用检测、性能计数宏 |
| `platform/` | → `true_ls2k0300/` | 各桥接层调用（Camera/IMU/Encoder/Motor/Assistant/SteeringMedia/Timer） |
| `platform/` | → 外部 | OpenCV JSON解析、Vendor SDK（`seekfree_assistant_interface`/`zf_device_uvc`等） |
| `legacy/` | → `port/` | 仅 inline 访问器（`Valid()`、`PixelCount()`等） |
| `legacy/` | → `legacy/` | 跨文件调用（感知管线编排、投影器、栅格、元素检测） |

### 2.2 调用关系热力图

```
         runtime  platform  legacy  port   true_ls2k
runtime    ●●●●      ●●      ●●●     ●●      ○
platform     ○       ●●       ○      ●●     ●●●
legacy       ○        ○      ●●●     ○       ○
port         ○        ○        ○      ●       ○
```

- ● = 密集调用, ●● = 中等调用, ●●● = 非常密集
- ○ = 无调用

### 3.1 diagnostics.hpp

```

  └── std::chrono::steady_clock::now()

GlobalDiagnosticRateLimiter()
  └── static DiagnosticRateLimiter (单例)

EmitRateLimited(diagnostics, event, interval_ms)
  ├── NowMs()                              [条件: event.timestamp_ms == 0]
  ├── GlobalDiagnosticRateLimiter()
  │     └── ShouldEmit()
  └── diagnostics.Emit()                   [virtual dispatch]

StdoutDiagnostics::Emit(event)
  ├── LevelString(level)                   [private static]
  └── std::cout/std::cerr << ...

StdoutDiagnostics::Info/Warn/Error/FailSafe(code, message)
  ├── Emit()                               [this]
  └── NowMs()

StdoutDiagnostics::LevelString(level)
  └── 纯 switch → const char*
```

PerfTicksPerUsX1000()                       → 原子加载

RecordPerfStage(stage, elapsed_ticks)

EmitPerfWindowDiagnostics(diagnostics, now_ms)

  ├── PerfCounterUsesArchCounter()

PerfScope::PerfScope(stage)                [RAII 构造函数]

PerfScope::~PerfScope()                     [RAII 析构函数]
