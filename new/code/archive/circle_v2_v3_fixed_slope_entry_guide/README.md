# Circle V2 V3 Fixed-Slope Entry Guide Archive

This directory keeps the retired V3 `P_est + fixed_slope` boundary-override
implementation as historical reference only.

The active runtime must not include or compile files from this directory. Any
future use of this implementation requires a new OpenSpec change and an active
spec update.
